# Jarvis_RUS

Локальный русскоязычный голосовой ассистент в стиле Джарвиса.
Слово-активатор, распознавание речи, языковая модель и синтез голоса работают на ПК.
Исключение: команды, которым нужен интернет (например, веб-поиск).

## Архитектура

микрофон -> слово-активатор -> распознавание речи (STT) -> «мозг» -> синтез голоса (TTS) -> колонки

«Мозг» состоит из трёх частей:
1. Быстрые команды по правилам: время, дата, громкость, запуск программ.
2. Диалог и рассуждения через локальную модель (Ollama).
3. Веб-поиск по запросу.

## Кандидаты компонентов (проверяем по ходу работы)

- Слово-активатор: Vosk (small ru) или openWakeWord
- Распознавание речи: Vosk, faster-whisper
- Языковая модель: Ollama
- Синтез голоса: Piper (русские голоса) + звуковые эффекты; позже клонирование голоса

## Запуск на другом ПК

    git clone https://github.com/zicevden-spec/Jarvis_RUS.git
    cd Jarvis_RUS
    python -m venv .venv
    .venv\Scripts\Activate.ps1
    pip install -r requirements.txt
    python src/jarvis/main.py
